# Dependencies

- Minecraft

&cRequired Mods:
- Meteor Client

- Fabric

Installation:
1. Install Fabric Loader for Minecraft.
2. Place mods JAR in .minecraft/mods folder
3. Launch Minecraft with Fabric profile
4. Enable module in Meteor Client menu


If you are a nerdy good boi and you want to build the mod by yourself, you can use the minecraft version of your choice as long as it's listed
in the following list:

&21.21.4, 1.21.5, 1.21.6, 1.21.7, 1.21.8, 1.21.10, 1.21.11

To do so, you can use the `buildAll` task or build specific versions using the custom `buildv_(version)` tasks. For more information, go check
the MULTIVERSION.md file on my GitHub.
